# 車両感覚トレーナー(Web版)

![version](https://img.shields.io/badge/version-1.0-ffd23f) ![platform](https://img.shields.io/badge/platform-ブラウザ-14213d) ![install](https://img.shields.io/badge/インストール-不要-2a9d8f)

車の「前・横・左前・後ろ」の感覚を、ぶつけずに練習できる3Dドライブシミュレーションです。
運転席から見た景色と真上から見た景色を並べて表示し、壁やポールまでの距離を数字で確かめながら動かせます。大きなボタンと文字で、運転に不安のある方やお年寄りにも使いやすくしています。

HTMLファイル1つだけで動きます。インストールもサーバーも不要です。

| 項目 | 内容 |
|---|---|
| バージョン | 1.0 |
| ファイル | `car_sense_trainer_web_v1.0.html` |
| 動作環境 | PC・スマホ・タブレットのブラウザ(WebGL対応の Chrome / Edge / Safari / Firefox 現行版) |
| 元になった版 | Python版 `car_sense_trainer_v1.0.py` のブラウザ版 |
| 標準の車種 | トヨタ プリウス(60系・日本仕様) |

## 遊び方

1. `car_sense_trainer_web_v1.0.html` をダウンロードして、ブラウザで開く
2. 最初に出る「使い方」を読んで「はじめる」を押す
3. 上のタブで練習をえらび、ボタンで車を動かす

GitHub Pages を有効にすれば、次のURLでそのまま公開できます。スマホでもこのURLを開くだけです。

```
https://<ユーザー名>.github.io/<リポジトリ名>/car_sense_trainer_web_v1.0.html
```

## 4つの練習

| 番号 | 練習 | お題 |
|---|---|---|
| 1 | 前の感覚 | 前の壁に近づき、50cm以内でぶつけずに止める(30cm以内なら ◎) |
| 2 | 左右の感覚 | ポールの間を通りぬけ、停止枠で左の塀から20〜40cmに寄せて止める |
| 3 | 左前の感覚 | 角のポールに車の左前の角を30cm以内まで近づけて止め、そのあと左の道へ曲がる |
| 4 | バック駐車 | 黄色い枠の駐車スペースにバックで入れ、白線の内側にまっすぐ止める |

お題を達成すると ◎ か ○ の結果と、ぶつかった回数が表示されます。

## 画面の見かた

- **大きい画面と小さい画面**: はじめは運転席からの景色と、真上からの景色です。「視点を変える」で切り替え、「入れ替え」で大小を入れ替えられます
- **距離の数字**: 「〜まで」の数字が障害物までの距離です。色で近さが分かります

| 色 | 距離 | 表示 |
|---|---|---|
| 緑 | 1m以上 | まだ余裕あり |
| 黄 | 1m未満 | 近づいています |
| オレンジ | 50cm未満 | かなり近い |
| 赤 | 30cm未満 | とても近い |

- **真上からの画面**: 運転席から見えない地面(紫)、ピラーで見えにくい方向(灰色)、予想進路(黄色)を重ねて表示します
- **左下の表示**: ギア、ハンドルの回転、速さ、ぶつかった回数

### えらべる視点(12種類)

運転席から / 真上から / 真上から(地図) / 斜め後ろから / 自由に動かす / バックカメラ / フロントカメラ / 左サイドカメラ / 右サイドカメラ / 左ドアミラー / 右ドアミラー / ルームミラー

運転席からの画面は、ドラッグ(指でなぞる)で見回せます。ダブルタップで正面に戻ります。

## 操作

ボタンは押しているあいだだけ動き、はなすと止まります。丸いハンドルを指やマウスで回すこともできます。

| 操作 | ボタン | キー(パソコン) |
|---|---|---|
| 前へ進む / 後ろへ下がる | ▲ / ▼ | ↑ / ↓ |
| ハンドルを左 / 右へ | ◀ / ▶ | ← / → |
| ハンドルをまっすぐに戻す | まっすぐに戻す | C |
| 止まる | ■ 止まる | スペース |
| はじめの位置に戻す | ↺ やり直し | R |
| 練習をえらぶ | 上のタブ | 1〜4 |
| 左 / 前 / 右 / 後ろを見る | 画面下のボタン | Q / F / E / G |
| 大きい画面の視点 / 小さい画面の視点 / 入れ替え | 視点を変える / 入れ替え | V / B / X |
| 音のあり・なし | 設定 | M |
| 使い方を開く | ？ | H |

## 設定

| 項目 | えらべる値 |
|---|---|
| 進む速さ | とてもゆっくり(2km/h)/ ゆっくり(4km/h)/ ふつう(7km/h) |
| 音(接近の警告音) | あり / なし |
| 予想進路の線 | 表示する / 表示しない |
| 死角(上からの画面) | 表示する / 表示しない |
| 距離の線(上からの画面) | 表示する / 表示しない |
| 地面の目盛り | 表示する / 表示しない |
| 文字の大きさ | ふつう / 大きい |

設定は、機器(ブラウザ)ごとに保存されます。

## ほかの車で練習する(車種エディタ)

「車種」→「車種を追加・編集する」で車種エディタが開きます。カタログの「主要諸元」にある寸法を入れるだけで、自分の車に近い形で練習できます。

- もとにできるひな形: プリウス(60系)/ 軽自動車・背の高いタイプ / ミニバン / SUV(プリウス以外は一般的な寸法の目安)
- 入力する主な項目: 全長、全幅、全高、ホイールベース、トレッド、最低地上高、最小回転半径、タイヤサイズ、ハンドルの位置(右 / 左)
- 目の位置や車体の形(ボンネット、ガラス、ミラー、カメラの高さなど)も調整でき、死角の見え方に反映されます
- 横から・上から見た図と、見えない地面の広さをその場で確認できます
- 車種データは JSON で書き出し・読み込みができ、ほかの機器へ移せます

追加した車種はその機器のブラウザの中に保存されます。標準の車種は書きかえられず、変更するとコピーとして保存されます。

## しくみ

- 3D描画: [three.js](https://threejs.org/) r160(HTMLに埋め込み済み)
- 外部への通信なし。オフラインでも動きます(ファイルサイズ 約1.1MB)
- 設定と追加した車種の保存: ブラウザの localStorage
- 画面は横長・縦長・スマホ横向きのそれぞれに合わせて配置が変わります
